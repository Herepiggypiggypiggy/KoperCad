# Glossary

| Term | Meaning |
| --- | --- |
| **Ampacity** | The current a conductor can carry continuously under stated conditions. See [Model or exact?](numbers.md#ampacity) |
| **Build mode** | Guided assembly at the plate, one step at a time. See [Build mode](workshop.md#build-mode) |
| **Cable** | A bundle of cores between two locations, with an optional shield. Proposed where wires cross a location boundary. |
| **Core** | One conductor inside a cable. |
| **Command search** | **Ctrl+K**: finds and runs every command. |
| **Cross reference** | A pointer from a coil to its contacts on other pages, and back. |
| **Device** | A drawn part with a tag, such as a contactor or a motor. |
| **Field file (`.kcfield`)** | Commissioning results and Build mode ticks exchanged between desk and tablet. |
| **IEC 81346** | The standard for reference designations: `=plant +location -device`. |
| **IEC 60617** | The standard for graphical symbols. KoperCAD uses it first; NFPA symbols are an alternative. |
| **Location** | A place in the plant such as the cabinet (`+CAB`) or the field (`+FLD`). |
| **Net** | All pins joined electrically by wires, junctions and terminals. |
| **PFHd** | Probability of a dangerous failure per hour, from functional safety (ISO 13849-1). An estimate here. |
| **Pin** | A connection point on a symbol. |
| **Potential** | A named level on a net, such as L1, N or 24 V. |
| **Proposal** | A wire the program suggests between two facing pins. Tab for the next, Enter accepts. |
| **Punch list** | Open items found during building or commissioning, each linked to a device or wire. |
| **Revision** | A numbered snapshot of the project that can be compared and restored. |
| **Service loop** | Extra wire length left at an end for connecting and servicing. |
| **Shield** | A screen around the cores of a signal cable, connected to PE, usually at one end. |
| **Tag** | The name of a device, such as `-K1`. |
| **Terminal strip** | A row of terminals on a rail where field cables meet the wiring in the cabinet. |
| **Workspace** | A layout of the window for one job: Schematic, Cabinet, 3D, Reports, Commissioning. |
