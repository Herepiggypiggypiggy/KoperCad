Release candidate 3 of the KoperCAD beta. Windows 10/11 only. No admin rights are needed.

## Files

- `KoperCAD-*-setup.exe`: per-user installer (installs under your profile).
- `KoperCAD-*-portable.zip`: unzip anywhere and double-click `run.cmd`; includes `kopercad-cli.exe`.
- `SHA256SUMS`: checksums of the two files above. `BUILD_INFO.txt`: version, commit and build time.

## Try these first

1. **Workshop pack.** One button makes the bench folder: the cut list, ferrules, labels, a checklist, a 1:1 drilling template, door cut-out cards and a print-scale check page. The bench packet is one printed PDF in working order.
2. **Single-line diagram.** Generate the power distribution drawing from a project: cable, protection, current and voltage drop per run, short-circuit current along each run with a breaking-capacity check, an optional diversity factor, and an "Enter supply data" button. The example project has a stated 400 V / 6 kA supply that is illustrative only.
3. **Wire numbering.** The Numbers tab lists every net; runs leave revision-locked pages alone. Try the Number button, then change the scheme.
4. **Parts table import.** Import a CSV or Excel parts list with the mapping step. Check the Dutch and German header words, the price list date, and the choice offered for repeated order numbers.
5. **Standards report.** The design verification section (wire sizing, protection, safety, heat) names its data source and assumptions.
6. **Cable runs in 3D.** Pick a duct to list its runs, the Run card, the lit path and the entry marker. Ducts are drawn as slotted duct and count in the heat model.
7. **Terminals by kind.** Terminal strips split by kind per location, with a bulk Set location.
8. **Safety sheets, PLC and symbols.** New safety relay, PLC CPU, network switch and fieldbus symbols (drawing symbols only, no safety function is evaluated), PLC pages from an I/O list (Siemens PIW/PQW and German PEW/PAW addresses are accepted), and one safety function per PDF page.
9. **Damaged project.** Ctrl+K "Recover a damaged project" opens a recovered copy and says what was kept and what was left out. A healthy file opens as itself, no copy.
10. **Print preview and plot sets.** Paper, scale, margins and saved plot sets.
11. **Ask Claude (optional).** Help > Ask Claude. See the caveats below before you rely on it.

## Changes you will notice

- **Starter macros are now fully wired** (with PE terminals and a "Three-phase supply" macro, 18 in all). A copy already installed is not replaced: **delete the Starter folder in My macros (or Company macros) and reopen the macro browser** to get the new ones.
- **Wire list column renamed.** "Cut length mm" is now "Route length mm", also in the CSV and Excel export. The ferrule allowance at each end is added on the bench cut list. A script that reads the old header name must be updated.
- **Cable length means the whole cable as bought** (since rc2): a core is cut at exactly that length, no loop added.
- **Issues, CLI, PDF, Python and Ask Claude now list the same problems.** `kopercad-cli check` lists open problems only; waived ones are left out.
- **PLC cards are tagged -A1, -A2 ...** instead of -K1 (existing projects keep their tags).
- **Opening a project adds report pages without an undo step.**
- Files written by the rc1 and rc2 builds are tested to still open and edit.

## Caveats

- **Not code-signed.** Windows SmartScreen may warn on first start: choose "More info", then "Run anyway".
- **Not verified on real Windows hardware.** The automated checks run on Linux and on a Windows build server without a GPU. The installer is checked there (per-user install, no admin rights, the app starts), but screens, the graphics start-up on older OpenGL-only laptops and the 3D view have not been looked at on real displays by the build process. Most of the new screens in this release have only been seen in Linux screenshots.
- **Ask Claude needs your own API key and has not been tested against the real API.** It is off until you turn it on, it sends the data scope you allow, plus what you press, and every edit it suggests can be undone.
- **Thermal and airflow results are models, not measurements.** The duct heat model is one coarse study.
- **Wire sizes, colours, breaking capacity checks and standard clause numbers are planning values.** The clause numbers are the authors' reading, not checked against a licensed copy of the standard. The short-circuit figures use the supply data you state, not a standards table, and the safety symbols carry no safety category or PL/SIL evaluation.
- Two wire-colour pixel checks and the `novo-cfd` simulation tests do not run on the Windows build server (no GPU; Linux covers the simulation tests).
