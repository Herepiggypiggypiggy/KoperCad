# Unreleased

- **Cable length now means the whole cable as bought.** A core on a cable with a stated Length (m) is cut at exactly that length; no service loop is added. Projects that typed the length of only the outside run into a cable will see those core lengths change: check the cable lengths before cutting.
- **Cabinet entry point and wire outside the entry** (Cabinet > Routes). Supply leads are routed to the entry and use the length you state outside it; until stated they stay estimates.
- A cable whose stated length is shorter than the wire's route inside the cabinet cannot reach the entry: its cores show the inside route as an estimate until the length is corrected.
- **Wire list column renamed.** "Cut length mm" is now "Route length mm" in the wire list, including the CSV and Excel export. The ferrule allowance at each end (10 mm by default, a project rule, so 20 mm for a wire with both ends) is added on the bench cut list (Route, +Ends, Cut). A script that reads the old header name must be updated.
- **Autopilot: wire rules per project.** Autopilot window > Wire rules: IEC 60204-1 (default) or House rules, with a colour per wire class (PE, PEN, neutral, 0 V, AC power, AC control, DC power, DC control) and a smallest section for power and control wires. Every colour reason names the rule ("house rule ... IEC 60204-1 would give BK"); a raised size says it was raised to the house minimum. Ampacity sizing is still planning values.
- **Autopilot: the review list is grouped by protective device.** One line per device ("-F2 (5 A) · 14 changes · 1.5 mm² · BK, RD"); open a group to see each wire and its reason, accept or tick a whole group.
- **Wires that break the project's house wire rules are listed in Issues** (warning "Wire breaks project rule"): a colour other than the house colour of its class, or a section under the house minimum. Only when the project uses House rules; wires without a value are left to the Autopilot. A waiver of the problem hides it.
