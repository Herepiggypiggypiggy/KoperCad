Release candidate 2 of the KoperCAD beta. Windows 10/11 only. No admin rights are needed.

## Files

- `KoperCAD-*-setup.exe`: per-user installer (installs under your profile).
- `KoperCAD-*-portable.zip`: unzip anywhere and double-click `run.cmd`; includes `kopercad-cli.exe`.
- `SHA256SUMS`: checksums of the two files above. `BUILD_INFO.txt`: version, commit and build time.

## Try these first

1. **AutomationML import.** Import a fresh `.aml` file. Pins and wires should line up, texts should be short, and long wires should be fast. The import report lists what was left out and what was guessed.
2. **Cabinet screen after an import.** Check the panels, Apply plate, All panels, readable tags, and the problems list (it says what it counts).
3. **Crane configurator import.** File > Import > Import crane configurator project. The report says how many devices are already held.
4. **3D tab.** Layers > Device shapes, Duct fill, the clearance zone and the hover card that names the schematic pages.
5. **Heat strip.** Cloud, Heat flow, the probe readout, pinned hot-spot labels and the verdict line.
6. **Commissioning.** Checks grouped under Wires, Terminals and Devices, and the guided walk (Space ticks the next check).
7. **Learn.** The lessons path; Skip does the step.
8. **Workshop pack.** One button makes the bench folder with the cut list, ferrules, labels, a checklist and a 1:1 drilling template.
9. **Ask Claude (optional).** Help > Ask Claude. See the caveats below before you rely on it.

## Caveats

- **Not code-signed.** Windows SmartScreen may warn on first start: choose "More info", then "Run anyway".
- **Not verified on real Windows hardware.** The automated checks run on Linux and on a Windows build server without a GPU. The installer is checked there (per-user install, no admin rights, the app starts), but screens, the graphics start-up on older OpenGL-only laptops and the 3D view have not been looked at on real displays by the build process.
- **Ask Claude needs your own API key and has not been tested against the real API.** It is off until you turn it on, it sends the data scope you allow, plus what you press (a picture you attach shows everything on screen, and an "... with Claude" button sends the text it shows), and every edit it suggests can be undone.
- **Thermal and airflow results are models, not measurements.** Treat temperatures and airflow as planning estimates.
- **Wire sizes, colours and standard clause numbers are planning values.** The clause numbers in the reasons are the authors' reading, not checked against a licensed copy of the standard.
- **Cable length changed meaning.** In an existing project that stated a cable's length as the run outside the cabinet, core lengths will shift: the cable length now means the whole cable as bought, and a core is cut at exactly that length (no loop added). Check the lengths before you cut.
- **Ask Claude asks for consent again.** Its data scopes changed (it can now read wire-number conflicts and a part from a datasheet PDF), so everyone who turned it on is asked once more before anything is sent.
- **Issued pages are locked by default.** Issuing a revision now locks the released pages, and you can restore a page or the project to an issued revision. Switch the lock off at issue time if you do not want it.
- Two wire-colour pixel checks and the `novo-cfd` simulation tests do not run on the Windows build server (no GPU; Linux covers the simulation tests).
