# Lesson anchors and signals

Generated by `cargo test -p novo-app anchors_doc` from `ANCHORS` and `SIGNALS` in
`crates/novo-app/src/app/learn.rs`. Do not edit by hand: run the test with
`UPDATE_ANCHORS_DOC=1` after adding one.

A control a lesson may point at (`point = { ui = "id" }`, `{ui:id}` in text, `clicked` and
`opened` checks) is an anchor. Its owner registers it every frame it is on screen with
`NovoApp::anchor` or `anchor_response`. Ids keep their name when a panel moves.

## Menus and their commands

Every menu of the bar and every command row in it is an anchor too, with no list to keep:
`{ui:menu.File}` is the menu in the bar and `{ui:cmd.export.sheets}` is the row of the command
with that id (`cmd.` + the command id). The card shows the row's own label. While the menu is
closed the ring points at the menu that holds the row.

## Folded controls

A cabinet bar button that has folded into **More** (a narrow window) points at
`cabinet.more` while it is not on screen.

## Signals

For `expect = { signal = "name" }`; raised where a key does not pass through a command.

- `proposal_next`
- `proposal_accept`
- `problem_waived`
- `waiver_restored`
- `cabinet_dropped`
- `cabinet_rotated`
- `cabinet_removed`
- `cabinet_plan_accepted`
