KoperCAD icon set · version 1 Phosphor for actions. Drawn icons for electrics. Generic actions (save, open, undo, search) keep Phosphor Regular, which the app already ships. Everything electrical gets a drawn icon from the same grid and stroke, so a contactor, a cable or a terminal strip reads as that at 16 pt and never as a generic glyph.
12 16 20 24 32 48
Rules
Stroke 1.5 on 24 (6.25 %), the same ratio as Phosphor Regular, so the two families sit together. Outline only. A filled dot marks a junction or node, nothing else is filled. One idea per icon. It is the IEC symbol itself or its simplest cut-out, never a pictogram of a product. Orientation as in a schematic: current runs top to bottom, supply at the top. Dashes only for a mechanical link (contactor), a boundary (macro) or a field (EMC). No colour in the icon. It takes the text colour; copper marks the active tool.
