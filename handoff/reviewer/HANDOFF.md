## What counts as blocking
- Real bugs, data loss, novo-core API contract breaks, CI or Windows breakage, and CLAUDE.md violations (`unsafe`; novo-core API changes from anyone but WS-02; shared dependencies outside `[workspace.dependencies]`).
- Anything that needs admin rights. The owner's rule: "Anything you build should function without admin rights, absolutely everything". That rules out Program Files, HKLM, elevation, machine-wide installs and services.
- Contradicting the design authority, docs/DESIGN.md (from #24 at c7f78ba; it replaces interaction-model.md and WORKFLOW.md):
  - Tab means next proposal; R and X orient.
  - There are no manual corner or T pieces; junctions are derived and routes are stored once.
  - There is one command field (I, Ctrl+K, or a tapped Space), and no menu bar or insert centre.
  - The context menu puts object actions first; on empty canvas, "repeat last tool" comes first.
  - Favourites on 1-9 work only while the field is empty.
  - Per-page tags are -K301, never -3K1.
- Style nits are non-blocking.
