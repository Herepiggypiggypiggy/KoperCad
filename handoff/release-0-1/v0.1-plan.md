# KoperCAD v0.1.0 beta: release plan

Written 2026-10-17 09:50Z by the release-plan thread. Base: main `04e89df` (#926), latest-build stamped 2026-10-17 09:19Z.
Goal (Tadjiro, 2026-10-17): a first stable build for test users, tested also by Claude as a visual test user (harness thread "Visual test-user harness"), open work finished, one complete version cut.

Defaults picked (change only with a reason): version `0.1.0` beta, tag `v0.1.0` on main; Windows 10/11 only; per-user install, no admin rights, offline; testers get the installer or a portable zip (or a git clone of `latest-build` plus `run.cmd`) with a short README that lists the known limitations.

Out of scope: all EPLAN connectivity and PLC export work (paused by Tadjiro until about 2026-10-19), CFD beyond what is already on main, new feature lanes.

## 1. Freeze rule

1. Feature freeze starts when this blocker list is accepted (target 2026-10-17 18:00Z). After that, a PR merges only if it fixes a blocker in section 3, fixes a bug found by a tester scenario in section 6, or is docs/tests. New features, new menus, restyles and refactors wait for v0.2.
2. Release candidate: when every blocker is merged and main CI (Linux and the Windows job) is green on one commit, Release dispatches a build of that exact commit (name it `0.1.0-rc1`). Only the harness scenarios and Tadjiro's own run decide go or no-go.
3. Soak: the RC runs the full scenario set (section 6) on Windows. Any S1 or S2 finding restarts the clock with a new RC; S3 goes to known limitations or v0.1.1.
4. Tag `v0.1.0` on the RC commit when the exit criteria (section 4) are all ticked. No pushes to a PR already marked READY (project rule); fixes go in new PRs from main.

Severity: S1 data loss, crash or cannot install/start. S2 a core workflow cannot be finished or a wrong number is shown as fact. S3 everything else.

## 7. Known limitations (draft, goes in the README and the release notes)

- Windows only; tested on Windows 10/11 x64. Built and verified mainly on Linux CI until the Windows pass (B6) completes.
- Light theme: some screens are not fully themed (Reports, Cabinet toolbar); dark is the supported theme.
- Heat and airflow are a physical model with a stated accuracy, not a certified thermal calculation.
- Functional safety: PFHd and performance levels are closed-form estimates ("model, not exact"); ISO 13849-1 table values are not sourced; this is not a SISTEMA replacement.
- Cable ampacity and derating tables are planning values from memory, not verified against the standard text; confirm against the standard before relying on them.
- Wire lengths are placeholders (`~`) until the cabinet is laid out and wires are routed.
- Report languages: English complete, Dutch for the assembly checklist and reports only, not the whole UI.
- Out of this release: EPLAN project and PLC export/import, symbol editor, label printer drivers (label CSV/PDF exist), multi-user editing.
- Parts library: only what the user imports; maker data and catalogues are not bundled.
- The 3D view has no mouse-drag slice plane (slider only); heat arrows have no hover value yet; no autosave interval setting (fixed), no custom symbol folder, terminal jumper numbers are automatic only.
- STEP import covers common geometry; some B-spline surfaces are approximated.

## 8. Model versus exact (labels the product must carry)

| Number | Status | Label |
|---|---|---|
| Wire lengths before routing | placeholder | `~` and "not routed" |
| Wire lengths after Route all | geometric, from the layout and duct model | "from layout" |
| Cable and wire ampacity, voltage drop | planning values, tables unverified | "planning value" |
| Short circuit and protection calculations | per formulas in `docs/PROTECTION.md`, inputs are the user's | show inputs |
| Heat, airflow, device temperatures | model with validation table (`docs/thermal-validation.md`) | fidelity badge and accuracy statement |
| PFHd, PL, SIL | closed-form estimate | "model, not exact" |
| Motor start current curve | estimate | "estimated" |
| Standards checks (IEC 60204-1, NFPA 79, UL 508A) | rule checks on the model, subset of the standard | "subset, not a certification" |
| Weights, costs | only from part data present | "no data" when empty |

## 10. Release notes (draft)

KoperCAD 0.1.0 beta. A local, offline electrical CAD program: draw IEC schematics with a keyboard-first workflow (Q search, wheel, smart duplicate), automatic potentials, tags, cross references, terminal strips and cables, generated reports with PDF and Excel export, design and standards checks, part catalogue and BOM, cabinet layout with rails, ducts and wire routing, a 3D cabinet view with heat and airflow, live circuit simulation, revisions, and a bench output (cut list, ferrules, labels, assembly checklist) for workshops. Install per user, no admin rights. Known limitations: see above. Report problems with Help > Report a problem.
