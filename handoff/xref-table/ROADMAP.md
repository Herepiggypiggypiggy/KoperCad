# Xref readability roadmap

1. Sheet contact table under a coil: one row per contact group, symbol, pins, page.column, compact/full density. (PR 1)
2. Relations tab symbol preview: thumbnail of each related symbol with tag, pins, page; click jumps. (PR 2)
3. Later: Shift+G list reuses the preview; click a table row on the sheet to jump to that contact.
