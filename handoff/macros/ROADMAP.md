# Macros: roadmap

Scope: reusable circuits saved to a per-user library, placed with automatic tags and wire numbers,
with preview, browser, rename/delete and file import/export. Design: `docs/design/macros.md`.

Next, in order (each a small draft PR):
1. Design note (this PR).
2. Macro file format, read and write, validation.
3. Library folder: list, save, rename, delete to trash, export/import.
4. Placement helper: wire numbers, preview summary.
5. Parts and cabinet offsets.
6. App: save macro, browser drawer, ghost preview.
7. Terminals inside macros (WS-02 review), update from library.

Open: whether terminals in a block need a core change (ask WS-02 at step 7).
