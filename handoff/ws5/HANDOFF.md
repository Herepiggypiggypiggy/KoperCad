## Layout (crates/novo-symbols)

- `symbols/iec/<category>/<name>.toml`: one file per symbol, and the source of truth. `build.rs` embeds them.
- `src/symbol.rs`: the `Symbol` struct, `bridges()` and `pass_through()` (which returns the `PassThrough` newtype).
- `src/validate.rs`: all the rules. BEHAVIOR_SCHEMA lists the allowed keys per kind; MAX_ALIAS_LEN is 12.
- `src/library.rs`: `Library` with `builtin`, `load_dir`, the lenient loaders, `by_function`, `by_alias` and `favorites`.
- `src/svg.rs` renders previews. `examples/gallery.rs` writes an HTML gallery.
- `tests/library.rs` holds the crate tests. `crates/novo-tests` (owned by the Tester) also loads the library, through `fixture_matches_library`.
- `FORMAT.md` is the format doc for other threads. Keep it in step with the code.

## How the TOMLs are made

They are generated by Python scripts kept in `handoff/ws-05-symbols/generator/`:
- `gen.py` is the base. It `exec`s `gen2.py`, then `gen3.py`, then `gen4.py`, and reads `aliases.py`.
- You may edit a TOML by hand instead. If you do, the generator no longer matches the files, so pick one approach and note it here.

To regenerate, from the generator folder:

```
rm -rf <repo>/crates/novo-symbols/symbols
python3 gen.py <repo>/crates/novo-symbols/symbols
```

Then run `git status`. Only the files you meant to change should differ.

## Decisions already made

- **Model mapping:** `SymbolKey` = `id`; pins = `connections` in file order (name = `id`, offset = `at`); `SymbolInstance::bridges` = `Symbol::bridges()`. Refreshes must match pins by designation, not by index.
- **`pass_through()` stays out of `bridges`:** it only propagates potential names. A changeover's paths are [common, break] and [common, make], and potentials flow outward from the side they arrive on.
- **What `bridges()` returns:** `conductor` and `overload` poles, plus the top-level `bridges` (for example PE to PE2 on drives, and series elements such as a CT primary or an ammeter).
- **Pole rule:** `conductor` poles may hold 2 or more ids. Other kinds take exactly 2, or 3 for a changeover `[common, break, make]`.
- **Aliases:** lowercase, 1 to 12 characters, unique within a library; `by_alias` trims and lowercases its input. Favourites are shipped defaults; user favourites live per user and are never written into the TOML files (no admin rights).
- **Accessories:** end pieces are under `accessory.terminal.*`, so `by_function("terminal")` returns only clamps.
- **Format:** stays at version 1. `aliases`, `favorite` and `center_off` were added before the first release.
- **Ids:** never rename or delete a shipped `id`.

## Traps

- Every connection must be on the 4 mm grid and must touch a line end or a bend. Tag anchors must not overlap the artwork; `clear_tag()` in `gen.py` shifts them.
- Arc angles are y-down, so they run clockwise.
- Delay arcs: operation moves the blade toward +x; on-delay uses arc 90..270 centred at blade x - 4, off-delay arc -90..90 centred at blade x - 5.5.
- Before pushing, check the PR is still open. Pushes made after a merge are lost, which is how #37 came about.
- Don't ask Tadjiro to review or merge. Work from events; don't run polling loops.
