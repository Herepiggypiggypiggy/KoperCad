# Cable and terminal strip plans: roadmap

Live reports, on screen, in PDF and as CSV, built on novo-reports.
1. Terminal diagram per strip, cable diagram: already on main (`terminals`, `cables`).
2. Cable schedule (`cableschedule`, flat, one row per core) and plug connection list (`plugs`): first PR.
3. Next: pin counts of plugs from the symbol/part (list unused pins), cable length from the cabinet layout, jumper/bridge rows in the terminal diagram, default generated pages for plugs.
